# Metrics

Metriche previste per le fasi successive:

- Durata media partite.
- Numero medio round.
- Eliminazioni per vite.
- Eliminazioni per Ferite Critiche.
- Pareggi sul valore piu' basso.
- Eliminazioni simultanee.
- Vita media residua vincitore.
- Ferite Critiche medie vincitore.
- Distribuzione valori giocati.
- Win rate per strategia.
- Win rate per colore.
- Confronto 2/3/4 giocatori.
